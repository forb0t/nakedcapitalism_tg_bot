# RSS-бот для Telegram

Telegram-бот, который присылает новые статьи из RSS/Atom-лент. Из коробки следит за
[Naked Capitalism](https://www.nakedcapitalism.com/), а администратор может добавить любые другие ленты прямо из бота.

## Возможности

- 📡 **Любые ленты** — RSS, Atom и RDF. Можно прислать ссылку на сайт — бот сам найдёт его ленту
- 🔔 **Подписки по лентам** — каждый пользователь выбирает, из каких лент получать уведомления
- 🆕 **Свежее** — общая лента статей со всех источников с постраничным просмотром
- 🔄 **Проверить** — проверить ленты, не дожидаясь расписания (не чаще раза в минуту)
- 🔍 **Поиск** по заголовкам и авторам (русский тоже), достаточно просто написать боту слово
- 🛠 **Управление лентами** для администратора: добавить, отключить, удалить
- 💾 История статей в SQLite, бережные запросы к сайтам (ETag / If-Modified-Since)

## Быстрый старт (Docker)

```bash
cp .env.example .env
# впишите в .env токен от @BotFather и свой Telegram ID
docker compose up -d --build
```

### Как узнать свой Telegram ID

Запустите бота и отправьте ему `/id` — он ответит числом. Впишите его в `ADMIN_IDS` и перезапустите бота:
`docker compose up -d`.

### Без Docker

```bash
pip install -r requirements.txt
export TELEGRAM_BOT_TOKEN=...
export ADMIN_IDS=123456789
python main.py
```

> ⚠️ Никогда не вписывайте токен в код и не коммитьте `.env` — токен из публичного репозитория
> украдут за минуты. Если токен утёк, отзовите его в @BotFather (*API Token → Revoke*).

## Настройки

Все настройки задаются переменными окружения (в `.env` для Docker):

| Переменная | По умолчанию | Описание |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | — | Токен бота от @BotFather (обязательно) |
| `ADMIN_IDS` | — | Telegram ID администраторов через запятую. Только они управляют лентами |
| `CHECK_INTERVAL_MINUTES` | `60` | Как часто проверять ленты (не меньше 5) |
| `BOT_TIMEZONE` | `Europe/Moscow` | Часовой пояс для времени публикации |
| `NAKEDCAP_DATA_DIR` | `.` (`/data` в Docker) | Где хранить базу `articles.db` и лог `bot.log` |
| `HTTPS_PROXY`, `HTTP_PROXY`, `ALL_PROXY` | — | Прокси для запросов к Telegram и сайтам |

## Добавление лент

Администратор может добавить ленту двумя способами:

1. **📡 Ленты → ➕ Добавить ленту** и прислать ссылку
2. Просто прислать боту ссылку в личном чате

Подойдёт как прямая ссылка на RSS/Atom, так и адрес сайта (`habr.com`, `meduza.io`) — бот найдёт ленту
по `<link rel="alternate">` или типовым адресам (`/feed`, `/rss`, `/rss.xml`…).

Статьи, которые уже есть в ленте на момент добавления, запоминаются молча — уведомления придут только о новых.
На странице ленты администратор видит ошибки последней проверки и может ленту отключить (⏸) или удалить (🗑).

## Команды

Всё управление — кнопками меню. Команд две:

| Команда | Что делает |
|---|---|
| `/start` | Открыть главное меню (новые пользователи подписываются на все ленты) |
| `/id` | Показать свой Telegram ID — нужен для `ADMIN_IDS`. В списке команд не показывается |

## Структура проекта

```
├── main.py         # точка входа
├── bot.py          # Telegram-бот: меню, команды, уведомления
├── feeds.py        # загрузка и разбор RSS/Atom, поиск ленты на сайте
├── storage.py      # SQLite: ленты, статьи, подписки (+ перенос базы из старой версии)
└── bot_config.py   # настройки из окружения
```

База из первой версии бота (только Naked Capitalism) переносится автоматически при первом запуске:
статьи и подписчики сохраняются.
